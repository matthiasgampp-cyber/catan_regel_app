# Catan & Städte & Ritter – Interaktive Regel-App

Eine mobile- & tablet-optimierte Regel-App für **Die Siedler von Catan** inklusive der Erweiterung **Städte & Ritter**.

## Features
- Vollständige Regelsuche & FAQ-Katalog (inkl. Kategoriefilter)
- Interaktiver Baukosten- & Rohstoffrechner
- Siegpunkt-Tracker
- Phasen-Guide & Spezialregeln
